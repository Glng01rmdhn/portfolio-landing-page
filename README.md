#  Personal Branding & Portfolio — Galang Ramadhan

Website **Personal Branding Landing Page** yang dirancang untuk menampilkan profil diri, rekam jejak prestasi **Taekwondo tingkat nasional**, serta kemampuan di bidang pengembangan web dan aplikasi (*Web & Mobile Development*).

🔗 **Live Demo:** [portfolio-landing-page.vercel.app](https://galang-portfolio-nine.vercel.app)

---

##  Fitur Utama

- **Taekwondo Achievements Slider:** *Horizontal card slider* interaktif yang dapat digeser menggunakan tombol navigasi maupun *scroll* roda mouse langsung, dilengkapi *modal pop-up* untuk melihat detail dan sertifikat kejuaraan.
- **Tech Stack & GitHub Showcase:** Menampilkan penguasaan teknologi *frontend* dan *mobile* beserta tautan langsung menuju profil GitHub.
- **Interactive UI & Animations:**
  - *Hero Entrance Animation* saat halaman pertama kali dibuka.
  - *Scroll Reveal* menggunakan `IntersectionObserver` saat halaman digulir.
  - *Custom Mouse Cursor Follower* khusus perangkat desktop.
- **Contact Section:** Form pesan interaktif beserta tombol akses cepat ke Telepon, Email, dan Instagram.

---

##  Teknologi yang Digunakan

- **HTML5** — Struktur halaman semantik
- **Tailwind CSS (CDN)** — *Utility-first styling* dan tata letak responsif
- **CSS3 (`style.css`)** — Animasi *keyframes*, transisi *hover*, dan *custom cursor*
- **Vanilla JavaScript (`script.js`)** — Kontrol *horizontal slider*, *modal pop-up*, navigasi mobile, dan *scroll observer*
- **Font Awesome** — Ikon antarmuka dan media sosial
- **Vercel** — *Hosting* dan *continuous deployment* dari GitHub
